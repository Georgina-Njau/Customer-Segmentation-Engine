 Customer-Segmentation-Engine using K means.

 This project uses K-means clustering algorithm to segment customers of the "Mall Customers" Kaggle dataset.
 (DATASET : https://www.kaggle.com/datasets/amisha0528/mall-customers-dataset?resource=download).The segmentation is based 
 on their "Annual Income" and "Spending Score" with the goal of identifying distcinct customer segments for data driven marketing
 and business intelligence.

 The algorithm features:
 a)Data loading and preprocessing
 b)Exploratory Data Analysis (EDA)
 c)Visualization of customer patterns
 d) Elbow Method for optimal cluster selection
 e)K-Means clustering
 f)Cluster visualizations with centroids and distinct clusters

SET UP INSTRUCTIONS:
Install all the required Python Libraries (pandas, numpy, matplotlib, seaborn, scikit-learn)
Run on colab or any compatible Python Environment.
